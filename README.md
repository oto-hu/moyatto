# Moyatto

**問いの形になっていない「もやもや」を、決められる問いに分けて閉じる Claude Code プラグイン。**
決めたことは台帳に残るので、同じことで迷い直しません。

頭に残り続けるのは、答えが出ない問いそのものより「何を決めればいいのかすら分からない状態」です。
Moyatto はそれを次の順で片づけます。

1. もやもやを、まとまっていないまま話す
2. 決められる問い（「〜するか」「AとBのどちらにするか」）に分ける
3. ほかの問いの前提になるものから順に並べる
4. 1つずつ閉じる：**今決める／期日と条件つきで保留／捨てる**
5. 閉じたら台帳に残す。保留は期日が来たら Claude Code を開いたときに知らせる

答えが出なくても、「いつ・何が分かったら決めるか」が決まれば、その問いは頭から出して大丈夫です。

## 導入

Claude Code で次の2行を実行します。

```
/plugin marketplace add oto-hu/moyatto
/plugin install moyatto@moyatto
```

動作環境は **macOS と Linux** です（Windows は未対応）。`python3` が必要です（macOS は標準で入っています。追加のパッケージは不要）。

## 使い方

| コマンド | すること |
|---|---|
| `/moyatto:moyatto [もやもや]` | もやもやを問いに分けて、1つずつ閉じる |
| `/moyatto:ledger` | 台帳を見る。期日が来た保留を1つずつ見直す |

「もやもやする」「ずっと迷っている」と話しかけるだけでも動きます。

## 台帳とプライバシー

- 台帳は **あなたのパソコンの `~/.moyatto/ledger.json` に** 保存されます（フォルダ・ファイルとも本人のみ読み書き可の権限）
- 台帳の中身は、Claude Code が問いを整理するときに、通常の会話と同じく Claude（Anthropic の API）に送られます。**それ以外の場所には送りません**（Moyatto のスクリプトはネットワーク処理も外部パッケージも使っていません）
- 台帳を消したいときは `~/.moyatto/` フォルダを削除してください

## 開発

```bash
python3 -m unittest discover -s tests -v
```
